# Giraffe World Website

A playful static website hosted on GitHub Pages featuring a Minecraft-style voxel giraffe greeting visitors!

## Files

- [index.html](index.html): The main webpage saying hello with Minecraft-inspired design.
- [giraffe.png](giraffe.png): A Minecraft-style blocky giraffe in a savanna biome.

## Deploying to GitHub Pages

1. Push your commits to GitHub:
   ```bash
   git add .
   git commit -m "Add homepage with Minecraft giraffe"
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch `main` and folder `/ (root)`, then click **Save**.
3. Your website will be live at `https://<your-username>.github.io/<repo-name>/`!
